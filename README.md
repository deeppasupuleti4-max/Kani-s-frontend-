# Kani's Studio — homepage starter

This is a React + Vite homepage starter based on the supplied visual reference:
- warm ivory background
- forest-green typography and announcement strip
- champagne-gold botanical line art
- editorial serif headline
- cropped reference fashion image

## Run
```bash
npm install
npm run dev
```

The homepage is a visual starting point. Navigation links and the menu button are presentation-only at this stage; product, cart, authentication and checkout routes will be connected to the existing backend in the next integration step.

The hero image is cropped from the reference screenshot supplied in this conversation. Replace `public/images/hero-reference.png` with a licensed original high-resolution image before public production use if you have the original photograph.
